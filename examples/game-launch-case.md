# Game Launch Case

## Scenario

一款SLG游戏计划国庆节上线，需要制定新游上线营销方案。

## Problem

需要解决：

-   如何快速建立用户认知
-   如何吸引目标玩家关注
-   如何促进预约和下载
-   如何在上线期间形成传播

## Recommended Analysis

-   SWOT
-   3C
-   AISAS
-   用户旅程模型
