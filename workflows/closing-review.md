# Closing Review 2.1

## Purpose

用于项目结案复盘。

------------------------------------------------------------------------

# Review Process

目标回顾

↓

执行回顾

↓

数据分析

↓

问题总结

↓

经验沉淀

↓

优化建议

------------------------------------------------------------------------

# Review Principles

区分：

-   项目实际数据
-   平台数据
-   行业参考数据
-   后续建议

------------------------------------------------------------------------

# Review Requirements

检查：

-   原始目标
-   实际执行
-   传播结果
-   品牌和用户变化
-   业务结果
-   客户反馈
-   优化空间

------------------------------------------------------------------------

# Data Rules

注意：

-   原方案、最终确认和实际执行之间的差异，先作为内部分析。
-   不默认将责任判断写入客户版本。
-   平台参考数据不得作为本项目结果。
-   曝光、互动不能直接证明销售或品牌提升。

------------------------------------------------------------------------

# Output

形成：

1.  项目总结
2.  成功经验
3.  问题分析
4.  后续优化建议
