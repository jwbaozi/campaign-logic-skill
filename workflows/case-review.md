# Case Review Workflow 2.1

## Purpose

用于 AI Marketing Strategy Skill 对营销项目进行结案复盘。

------------------------------------------------------------------------

# Review Flow

目标回顾

↓

执行回顾

↓

数据分析

↓

问题总结

↓

经验沉淀

↓

优化建议

------------------------------------------------------------------------

# Review Principles

必须区分：

-   项目实际数据
-   平台数据
-   行业参考数据
-   后续建议

避免将参考数据误认为项目结果。

------------------------------------------------------------------------

# Output Structure

## 1. Project Objective

回顾项目初始目标。

## 2. Execution Review

分析实际执行情况。

## 3. Data Analysis

结合数据判断效果。

## 4. Key Findings

总结成功经验与问题。

## 5. Optimization Suggestions

提出下一阶段建议。
