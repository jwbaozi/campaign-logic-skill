# Case Review v2.2

## Purpose

用于帮助 AI Marketing Strategy Skill
对营销案例进行分析、拆解和经验沉淀。

升级目标：

-   理解案例背景与目标
-   分析策略逻辑
-   识别使用的方法论
-   提炼有效呈现方式
-   沉淀可复用策略资产

------------------------------------------------------------------------

# Case Review Workflow

案例输入

↓

项目背景分析

↓

目标分析

↓

策略拆解

↓

执行拆解

↓

效果分析

↓

方法论识别

↓

呈现模型识别

↓

经验沉淀

↓

未来应用建议

------------------------------------------------------------------------

# Review Dimensions

## 1. Case Background Review

分析：

-   品牌背景
-   市场环境
-   用户需求
-   商业挑战

判断：

案例解决的核心问题是什么。

------------------------------------------------------------------------

## 2. Objective Review

分析：

-   项目目标
-   用户目标
-   商业目标
-   传播目标

检查：

目标是否清晰，并能够支持后续策略设计。

------------------------------------------------------------------------

## 3. Strategy Review

分析：

-   核心策略是什么
-   策略如何解决商业问题
-   洞察如何推导策略

重点关注：

洞察

↓

策略

↓

执行

↓

结果

是否形成完整链路。

------------------------------------------------------------------------

# 4. Methodology Identification

识别案例中使用的策略方法论。

包括：

-   SWOT
-   PEST
-   3C
-   AISAS
-   AIPL
-   SMART
-   5W2H
-   SCQA
-   HOOK
-   HBG
-   KISS
-   其他营销模型

------------------------------------------------------------------------

## Methodology Output

输出：

Methodology:

方法论名称

Application:

案例中的应用方式

Learning:

该方法论为什么有效

Visual Reference:

如存在：

`assets/methodology/xxx.png`

------------------------------------------------------------------------

# 5. Presentation Model Identification

识别案例中的方案呈现方式。

包括：

-   用户旅程
-   营销漏斗
-   时间轴
-   内容矩阵
-   品牌战略结构
-   全链路营销模型

------------------------------------------------------------------------

## Presentation Output

输出：

Presentation Model:

呈现模型名称

Application:

案例中的应用方式

Learning:

为什么这种表达方式有效

Visual Reference:

如存在：

`assets/presentation/xxx.png`

------------------------------------------------------------------------

# 6. Execution Review

分析：

-   平台选择
-   内容规划
-   资源组合
-   时间节奏
-   用户触达方式

判断：

执行是否支持策略目标。

------------------------------------------------------------------------

# 7. Result Review

分析：

-   项目效果
-   用户反馈
-   商业价值
-   传播效果

区分：

-   已知数据
-   案例公开信息
-   推测分析

------------------------------------------------------------------------
