# Proposal Review v2.2

## Purpose

用于帮助 AI Marketing Strategy Skill 对营销方案进行系统检查。

除检查方案完整性、策略逻辑和执行可行性外，增加：

-   方法论适配检查
-   呈现模型检查
-   视觉表达建议

------------------------------------------------------------------------

# Proposal Review Workflow

方案输入

↓

客户与项目背景检查

↓

目标检查

↓

数据与洞察检查

↓

策略逻辑检查

↓

方法论适配检查

↓

方案呈现检查

↓

执行落地检查

↓

效果指标检查

↓

输出优化建议

------------------------------------------------------------------------

# Review Dimensions

## 1. Client & Project Background Review

检查：

-   客户背景是否清晰
-   项目目标是否明确
-   商业问题是否被准确理解

关注：

背景信息是否支持后续策略推导。

------------------------------------------------------------------------

## 2. Objective Review

检查：

-   目标是否明确
-   是否可衡量
-   是否与商业目标一致

如目标模糊：

建议使用：

`assets/methodology/SMART.png`

辅助目标拆解。

------------------------------------------------------------------------

## 3. Data & Insight Review

检查：

-   数据来源是否可靠
-   数据是否支持洞察
-   洞察是否能够推导策略

判断：

数据 → 洞察 → 策略

是否形成完整逻辑链。

------------------------------------------------------------------------

# 4. Strategy Methodology Review

检查：

## Methodology Fit

判断：

-   使用的方法论是否适合当前问题
-   方法论是否帮助解决策略问题
-   是否存在更合适的分析框架

------------------------------------------------------------------------

## Recommended Output

如果方案缺少合适的方法论：

输出：

Recommended Methodology:

方法论名称

Why:

推荐原因

Visual Reference:

对应图片：

`assets/methodology/xxx.png`

Application:

建议应用章节。

------------------------------------------------------------------------

# 5. Strategy Logic Review

检查：

-   核心策略是否由洞察推导
-   策略是否指导执行
-   执行动作是否服务策略目标

重点检查：

洞察

↓

策略

↓

资源

↓

执行

↓

指标

是否闭环。

------------------------------------------------------------------------

# 6. Presentation Model Review

检查：

-   方案结构是否清晰
-   信息表达是否符合客户理解方式
-   是否需要使用结构化呈现模型

------------------------------------------------------------------------

## Recommended Presentation Output

如果方案需要优化表达：

输出：

Recommended Presentation Model:

模型名称

Why:

适用原因

Visual Reference:

对应图片：

`assets/presentation/xxx.png`

Suggested PPT Section:

建议应用页面。

------------------------------------------------------------------------

# 7. Execution Review

检查：

-   平台选择是否合理
-   内容规划是否明确
-   时间安排是否可执行
-   资源分配是否匹配目标

------------------------------------------------------------------------

# 8. Measurement Review

检查：

-   指标是否对应目标
-   数据是否可追踪
-   效果评估方式是否明确

------------------------------------------------------------------------

# Visual Asset Integration Rule

当推荐方法论或呈现模型时：

如果存在对应视觉资产：

必须提供：

1.  模型名称
2.  推荐原因
3.  图片参考路径
4.  应用场景

不要只提供文字建议。
