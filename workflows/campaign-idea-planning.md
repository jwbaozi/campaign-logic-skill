# Campaign Idea Planning Workflow

Use for marketing moments, holidays, promotions, launches, anniversaries, events, and hot-topic participation.

1. Read `workflows/intake.md`; identify brand/product, objective, audience, every named moment/season/event, every product-launch or important communication requirement, available channels, and constraints.
2. Build a Node & Launch Coverage Matrix before ideation. Each named item must receive relevance, target action, direct gameplay, destination, KPI, risk, and trend status; do not drop lower-priority or future items.
3. Invoke `logic/marketing_moment_campaign_idea_engine.md`. Read `knowledge/09-marketing-moments/node-and-launch-playbook.md`, plus specific references such as `teacher-day.md`. For every matrix row, run `workflows/node-benchmarking.md` or mark the comparison `【缺失】`.
4. Produce three or more differentiated creative territories unless the user requests a shorter output. Then map the selected territory or a tailored variant to every matrix row.
5. If the brief requests a current meme or hot topic, run `workflows/trend-scan.md` for every near-term row before selecting it. For future rows, state `在实际发布前 T-14 至 T-7 重新扫描并做平台、权益与品牌安全核验` and provide a durable mechanism now.
6. Select or recommend a route using explicit trade-offs: brand fit, expected behavior change, distinctiveness, feasibility, risk, and evidence needed.
7. Convert selected routes through `logic/execution_planning_engine.md`; include warm-up, launch, sustain, conversion, and retention as applicable.
8. Use `workflows/knowledge-routing.md` for only the knowledge needed to settle a decision. Use presentation assets when the user asks for a proposal structure, strategy diagram, or visual report.
