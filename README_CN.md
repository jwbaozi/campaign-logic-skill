# AI营销策略 Skill

[English](README.md) \| [简体中文](README_CN.md)

## 从 Campaign Logic Engine 到完整营销策划 Agent

AI营销策略 Skill 是从 Campaign Logic Skill 升级而来的 AI 营销策略助手。

它帮助营销人员从需求理解、策略制定、方案审核，到营销知识调用和方案呈现优化，提升营销策划效率和专业度。

## 核心能力

### Brief 分析

理解：

-   项目背景
-   商业目标
-   营销需求
-   信息缺失项

### 策略制定

支持：

-   市场分析
-   用户洞察
-   策略推导
-   营销模型选择

### 方案审核

分析：

-   逻辑完整性
-   策略匹配度
-   执行可行性
-   指标设计

### 营销知识体系

包含：

-   策略方法论
-   品牌理论
-   方案呈现模型
-   广告知识
-   媒体指标
-   产品卖点
-   营销表达
