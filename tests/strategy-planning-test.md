# Strategy Planning Test

## Input

一款SLG游戏计划国庆节上线，需要制定新游营销方案。

## Expected Routing

应该调用：

-   Strategy Methodology
-   Presentation Models
-   Advertising Knowledge
-   Media Metrics

## Expected Output

应包含：

1.  市场分析
2.  用户洞察
3.  产品卖点
4.  传播策略
5.  投放规划
6.  效果评估

## Evaluation

检查：

-   是否选择合适方法
-   是否解释选择原因
-   是否连接业务目标
