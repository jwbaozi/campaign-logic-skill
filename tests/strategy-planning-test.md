# Strategy Planning Test

## Purpose

验证新游上市规划是否形成从业务目标到媒介与效果评估的完整链路。

## Input

> 一款 SLG 游戏计划国庆节上线，需要制定新游营销方案。

## Expected Routing

- Strategy Methodology
- Presentation Models
- Advertising Knowledge
- Media Metrics

## Expected Output

1. 市场分析
2. 用户洞察
3. 产品卖点
4. 传播策略
5. 投放规划
6. 效果评估

## Pass Criteria

- 选择合适方法。
- 解释选择原因。
- 连接业务目标。
