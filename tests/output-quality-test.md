# Output Quality Test

## Purpose

验证输出是否能从证据走到决策与行动，而不是停留在概念或模板话术。

## Required Quality Criteria

- 有明确分析逻辑与业务场景结合。
- 有方法依据，并说明推荐原因。
- 有执行建议与从证据到决策再到动作的可追溯因果链。
- 对关键问题提供原内容、原因、后果和可直接替换内容。
- 将执行写到责任、节奏、承接、投放和可测量指标。

## Failure Conditions

- 堆砌模型或只解释概念。
- 输出空泛营销语言。
- 用“话题 + KOL + 直播 + 抽奖”复制成多条伪差异化创意。
- 用方法论或知识库替代对材料本身的判断。
