# Campaign Review Test

## Purpose

验证方案审核是否先诊断逻辑问题，再提供可执行的优化建议。

## Input

> 上传一份营销方案，请检查逻辑。

## Expected Routing

- Campaign Review Workflow
- Marketing Expression
- Presentation Models

## Expected Output

- 项目背景
- 营销目标
- 用户洞察
- 策略逻辑
- 执行方案
- 指标设计

## Pass Criteria

- 不直接重写整份方案。
- 先发现问题，再提出优化建议。
