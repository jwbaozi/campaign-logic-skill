# Methodology Categories

## Strategic Analysis

用于分析市场环境、竞争格局和企业机会。

------------------------------------------------------------------------

## SWOT

### Purpose

分析企业优势、劣势、机会和威胁。

### Suitable Scenarios

适用于：

-   企业战略分析
-   品牌竞争环境分析
-   市场机会判断

### Visual Reference

`assets/methodology/SWOT.png`

### Output Guidance

推荐 SWOT 时，需要说明：

1.  为什么适合当前项目
2.  分析哪些战略因素
3.  建议放入方案哪个章节

# Methodology Output Rule

当 AI 推荐方法论时，必须输出：

## Recommended Methodology

推荐使用的方法论。

## Why

为什么适合当前项目。

## Application

如何应用到策略方案。

## Visual Reference

对应视觉参考：

`assets/methodology/xxx.png`

## Suggested PPT Section

建议放入方案章节。
