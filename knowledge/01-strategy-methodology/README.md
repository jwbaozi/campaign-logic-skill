# Strategy Methodology Knowledge

## Purpose

用于帮助 AI Marketing Strategy Skill 根据营销问题选择合适的方法论。

## Usage Logic

问题识别 ↓ 选择方法 ↓ 解释为什么使用 ↓ 应用到方案阶段

## Method Categories

### Strategic Analysis

-   SWOT
-   PEST
-   3C

### Goal Planning

-   SMART
-   5W2H

### Consumer Journey

-   AISAS
-   AIPL

### Communication Strategy

-   SCQA
-   HBG
-   HOOK
-   KISS

## Output Requirement

推荐方法时需要说明：

1.  方法解决什么问题
2.  为什么适合当前场景
3.  应用于方案哪个章节
