# Strategy Methodology Knowledge

## Purpose

用于帮助 AI Marketing Strategy Skill
根据营销问题选择合适的方法论，并辅助完成策略推导。

原模块定位： 问题识别 → 选择方法 → 解释使用原因 → 应用于方案阶段。

------------------------------------------------------------------------

# Usage Logic

营销问题识别\
↓\
判断策略任务类型\
↓\
选择方法论\
↓\
分析与推导策略\
↓\
推荐方案章节与呈现方式

------------------------------------------------------------------------

# Method Categories

## Strategic Analysis

### SWOT

Purpose: 分析企业内部优势、劣势以及外部机会和威胁。

Applicable Scenario: - 品牌战略判断 - 市场机会分析 - 竞争环境分析

Output: 明确战略方向和机会点。

Related Presentation: SWOT矩阵。

------------------------------------------------------------------------

### PEST

Purpose: 分析宏观环境变化。

Applicable Scenario: - 行业趋势 - 市场进入判断 - 政策环境分析

Output: 解释项目为什么需要发生。

Related Presentation: 环境分析框架。

------------------------------------------------------------------------

### 3C

Purpose: 分析企业、消费者和竞争关系。

Applicable Scenario: - 品牌定位 - 市场策略制定

Output: 找到品牌竞争机会。

Related Presentation: 三角模型。

------------------------------------------------------------------------

## Goal Planning

### SMART

Purpose: 帮助定义明确目标。

Applicable Scenario: - 项目目标制定 - KPI设定

Output: 具体、可衡量的目标。

------------------------------------------------------------------------

### 5W2H

Purpose: 拆解执行计划。

Applicable Scenario: - Campaign规划 - 活动执行

Output: 明确执行要素。

------------------------------------------------------------------------

## Consumer Journey

### AISAS

Purpose: 分析数字时代消费者决策路径。

Applicable Scenario: - 内容传播 - 社交媒体策略

Output: 用户从认知到分享的行为路径。

------------------------------------------------------------------------

### AIPL

Purpose: 分析用户资产沉淀。

Applicable Scenario: - 品牌运营 - 用户增长

Output: 用户关系变化路径。

------------------------------------------------------------------------

## Communication Strategy

### SCQA

Purpose: 构建策略叙事逻辑。

Applicable Scenario: - 提案开场 - 策略说明

Output: 问题、冲突、答案结构。

------------------------------------------------------------------------

### HBG

Purpose: 分析品牌增长来源。

Applicable Scenario: - 品牌增长策略

------------------------------------------------------------------------

### HOOK

Purpose: 设计内容吸引机制。

Applicable Scenario: - 短视频 - 内容营销

------------------------------------------------------------------------

### KISS

Purpose: 复盘经验和持续优化。

Applicable Scenario: - 项目总结 - 方法沉淀

------------------------------------------------------------------------

# Output Requirement

推荐方法时必须说明：

1.  方法解决什么问题
2.  为什么适合当前场景
3.  应用于方案哪个章节
4.  推荐对应呈现模型
