# Method Categories

## Strategic Analysis

### SWOT

用于分析企业内部优势、劣势以及外部机会、威胁。

适用： - 市场机会判断 - 品牌战略分析 - 竞争环境分析

输出： 帮助明确战略方向。

------------------------------------------------------------------------

### PEST

用于分析宏观环境变化。

适用： - 行业趋势分析 - 市场背景分析

输出： 解释市场环境为什么影响项目。

------------------------------------------------------------------------

### 3C

用于分析企业、消费者和竞争关系。

适用： - 品牌定位 - 市场策略制定

输出： 寻找竞争机会。

------------------------------------------------------------------------

## Goal Planning

### SMART

用于制定明确目标。

适用： - 项目目标 - KPI规划

------------------------------------------------------------------------

### 5W2H

用于拆解执行计划。

适用： - 营销活动规划 - 执行方案制定

------------------------------------------------------------------------

## Consumer Journey

### AISAS

用于分析消费者在数字环境中的行为路径。

适用： - 内容传播 - 社交媒体策略

------------------------------------------------------------------------

### AIPL

用于分析用户从认知到忠诚的关系变化。

适用： - 用户运营 - 品牌增长

------------------------------------------------------------------------

## Communication Strategy

### SCQA

用于建立策略表达逻辑。

适用： - 提案逻辑 - 策略说明

------------------------------------------------------------------------

### HBG

用于分析品牌增长。

------------------------------------------------------------------------

### HOOK

用于内容吸引机制设计。

适用： - 短视频 - 内容传播

------------------------------------------------------------------------

### KISS

用于复盘和经验沉淀。

------------------------------------------------------------------------
