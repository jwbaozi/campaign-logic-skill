# Presentation Output Rule

当 AI 推荐呈现模型时，必须输出：

## Recommended Presentation Model

推荐使用的呈现模型。

## Why

为什么适合当前方案。

## Visual Reference

对应图片路径：

`assets/presentation/xxx.png`

## Suggested PPT Section

建议应用于方案哪个章节。

------------------------------------------------------------------------
