# Presentation Models Knowledge

## Purpose

用于帮助 AI Marketing Strategy Skill
根据项目需求推荐合适的方案呈现模型。

## Usage Logic

项目目标 ↓ 判断信息表达需求 ↓ 选择合适模型 ↓ 说明模型价值 ↓
应用到PPT对应章节

## Model Categories

### User Journey

-   AISAS
-   AIPL

### Business Analysis

-   PEST
-   3C
-   SWOT

### Marketing Planning

-   人货场
-   全链路营销模型
-   内容营销模型

## Output Requirement

推荐模型时需要说明：

1.  为什么适合当前项目
2.  解决什么表达问题
3.  建议放在方案哪个章节
