# IMA Search Query Template

## Purpose

帮助用户在IMA知识库中快速找到相关资料。

---

# Market Analysis

模板：

[行业]
+
市场趋势 / 市场规模 / 行业发展

示例：

新能源汽车
+
市场趋势

---

# Consumer Insight

模板：

[行业]
+
消费者需求 / 用户行为 / 消费趋势

示例：

咖啡
+
年轻消费者消费行为

---

# Competitor Analysis

模板：

[行业]
+
竞争格局 / 品牌竞争 / 市场份额

示例：

智能手机
+
品牌竞争格局

---

# Marketing Case

模板：

[行业]
+
营销案例 / 品牌案例 / 增长案例

示例：

食品饮料
+
品牌营销案例

---

# Search Optimization Principle

不要只搜索：

❌ "营销"

建议：

行业 + 问题 + 研究方向

例如：

✅ "宠物食品 用户消费趋势"

✅ "新能源汽车 用户购买决策"
