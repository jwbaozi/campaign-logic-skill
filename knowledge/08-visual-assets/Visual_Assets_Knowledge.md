# Visual Assets Knowledge v2.3

## Purpose

用于管理并调用营销方法论和方案呈现模型视觉资产。

目标：

-   推荐方法论时直接展示对应图片
-   推荐呈现模型时直接展示对应图片

------------------------------------------------------------------------

# Asset Usage Rule

When an asset exists:

必须展示图片。

不要只输出路径。

------------------------------------------------------------------------

# Output Principle

用户需要看到：

图片 + 模型解释 + 应用建议

而不是：

模型名称 + 文件路径。
