# Product Selling Points Knowledge

## Purpose

用于帮助 AI Marketing Strategy Skill 分析：

> 产品为什么值得购买？

解决：

- 产品优势如何提炼
- 用户为什么选择
- 卖点如何转化为营销表达

---

## Knowledge Scope

包含：

- 产品功能分析
- 用户利益点分析
- 差异化卖点
- 卖点表达优化

---

## Usage Logic

产品信息

↓

识别核心能力

↓

转换用户价值

↓

提炼传播卖点

↓

应用到营销方案

---

## Output Requirement

提炼卖点时需要说明：

1. 产品特点是什么
2. 对用户有什么价值
3. 与竞品相比有什么差异
4. 如何用于传播
