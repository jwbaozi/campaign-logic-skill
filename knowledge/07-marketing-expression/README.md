# Marketing Expression Knowledge

## Purpose

用于帮助 AI Marketing Strategy Skill 优化营销方案中的表达方式。

解决：

- 表达是否专业
- 是否体现商业价值
- 是否符合客户沟通场景

---

## Knowledge Scope

包含：

- 营销表达优化
- 策略语言转换
- 用户价值表达
- 商业结果表达

---

## Usage Logic

原始表达

↓

识别问题

↓

优化表达结构

↓

输出更清晰的营销语言

---

## Output Requirement

优化表达时需要：

1. 保留原始业务含义
2. 避免无意义营销黑话
3. 强化用户价值
4. 体现商业目标
