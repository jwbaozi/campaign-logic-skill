# Advertising Knowledge

## Purpose

用于帮助 AI Marketing Strategy Skill
理解广告运作逻辑、投放机制和广告效果分析。

## Knowledge Scope

包含：

-   广告基本概念
-   广告竞价逻辑
-   投放优化逻辑
-   广告指标体系
-   转化分析

## Usage Logic

用户问题

↓

判断广告相关需求

↓

调用广告知识模块

↓

结合营销目标输出策略建议

## Output Requirement

分析广告问题时，需要说明：

1.  当前问题属于什么环节
2.  应关注哪些指标
3.  可以采取哪些优化方向
