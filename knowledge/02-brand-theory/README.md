# Brand Theory Knowledge

## Purpose

用于帮助 AI Marketing Strategy Skill 理解品牌建设相关问题。

解决：

-   品牌为什么需要建设
-   如何建立品牌定位
-   如何提升品牌资产

------------------------------------------------------------------------

## Knowledge Scope

包含：

-   Brand Value 品牌价值
-   Brand Equity 品牌资产
-   Brand Positioning 品牌定位
-   CBBE模型
-   Aaker品牌理论
-   品牌金字塔
-   品牌价值链

------------------------------------------------------------------------

## Usage Logic

用户问题

↓

判断是否涉及品牌建设

↓

选择对应品牌理论

↓

结合业务场景输出策略建议

------------------------------------------------------------------------

## Output Requirement

推荐理论时需要说明：

1.  为什么选择该理论
2.  解决什么品牌问题
3.  应用于方案哪个阶段
