# Media Metrics Knowledge

## Purpose

用于帮助 AI Marketing Strategy Skill
判断营销投放效果，并选择合适的衡量指标。

## Knowledge Scope

包含：

-   CTR
-   CVR
-   CPA
-   ROI
-   LTV
-   漏斗分析
-   素材效果分析
-   转化路径分析

## Usage Logic

营销目标

↓

判断衡量阶段

↓

选择对应指标

↓

分析问题原因

↓

提出优化方向

## Output Requirement

分析指标时需要说明：

1.  指标代表什么
2.  当前阶段为什么关注该指标
3.  指标变化说明什么问题
4.  后续优化方向
