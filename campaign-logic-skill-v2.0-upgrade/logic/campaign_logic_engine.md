# Campaign Logic Engine

## 定位

继承 Campaign Logic Skill 核心能力，作为新版 AI Marketing Strategy Skill 的 Campaign审核模块。

## 检查维度

1. 目标检查
- 营销目标是否明确
- 用户、行为、指标是否清晰

2. 洞察检查
用户洞察 → 策略 → 创意动作 是否形成逻辑链。

3. 策略检查
执行动作是否真正解决营销问题。

4. 传播链路检查

认知 → 兴趣 → 互动 → 转化 → 沉淀
